# Student Path Guide
## Description

Student Path Guide is an application design to help high school learners make informed decisions about their future careers and university pathways.

Many students-especially pthose from underprivileged backgrounds-lack access to accurate and structured information about career options, univeristy requirements, and subject choice. this often leads to poor decisons that affect their long-term opportunities.

This project aims to bridge that gap by providing students with the tools and guidance they need to confidently choose a career path that aligns with their interests and academic performance.

##feature
-Course Finder
Helps students discover courses they qualify for based on their subjects and results
-AI Chat assistant 
Provides guidance, answers questions, and explains career options in a simple way.

##Usage
-Run the application
-Enter your subjects and results(if applicable)
-Explore recommended courses
-Use the AI assistant to ask questions abdout careers and study paths
